ARDMAN — мастерская, мобильная версия и фотографии
28 сентября 2026

УСТАНОВКА
1. Перед заменой сохраните копию вашей папки сайта, если в ней есть неопубликованные правки.
2. Распакуйте обновление в папку ardman-portfolio с заменой файлов. Папка assets должна объединиться с существующей.
3. GitHub Desktop: Commit → Push origin. Дождитесь завершения публикации.
4. Обновите страницу Ctrl+F5. На телефоне перезагрузите страницу.
Полный архив содержит все файлы, нужные текущим карточкам. Пакет обновления предназначен для предыдущей версии с 565 карточками.

МАСТЕРСКАЯ
Откройте адрес сайта, добавив admin.html после последнего слеша.
Например: https://serebryakovjun-ui.github.io/ardman-portfolio/admin.html
Выберите объект или нажмите «Добавить объект». Введите название, регион, город, дату, покрытие и описание.
Дата может быть пустой. Для архивного материала выберите «Архивная публикация».
Фото: JPEG, PNG или WebP, до 40 МБ за один файл. HEIC предварительно сохраните в JPEG.
«На обложку» ставит фото первым. Стрелки меняют порядок. «Предпросмотр» показывает текущую карточку.
Оригиналы новых фото сохраняются без перекодирования; для каталога создаются копии до 480 и 960 пикселей без увеличения исходного изображения.
Черновик и новые фото автоматически сохраняются в IndexedDB этого браузера.
Дождитесь надписи «Черновик сохранён» перед закрытием. В приватном режиме и при нехватке места сохранение может быть недоступно — смотрите статус.
Очистка данных браузера удаляет черновики. Скачивайте ZIP как резервную копию.

ПУБЛИКАЦИЯ
Нажмите «Скачать обновление ZIP», распакуйте его в репозиторий и выполните Commit → Push origin.
Скачанный ZIP не публикует сайт автоматически. Черновики не синхронизируются между устройствами.
После публикации нажмите «Начать с опубликованной базы». Предыдущий черновик можно восстановить отдельной кнопкой.
Если сайт изменился после создания черновика, мастерская предложит выбрать опубликованную базу или ваш черновик.
Не публикуйте одновременно разные ZIP с разных устройств: каждый содержит полный objects.json.
Мастерская работает локально в браузере и не имеет права записывать на сервер. Парольная админка и прямая публикация требуют отдельного сервера/авторизации; они не подключены.

МОБИЛЬНАЯ ВЕРСИЯ
Фильтры каталога раскрываются кнопкой. Элементы управления увеличены для касаний.
В полном просмотре листайте фото горизонтальным свайпом. При увеличении снимка свайп перелистывания отключён, чтобы можно было рассматривать детали.
Для выбранного региона добавлена кнопка «Показать регион целиком».

ФОТОГРАФИИ И ПОВТОРЫ
Каталог и галерея используют лёгкие версии с адаптивным выбором размера.
Полный просмотр загружает оригинал; спустя короткую паузу подгружается максимум один следующий кадр. При режиме экономии трафика предзагрузка отключена, если браузер сообщает этот режим.
565 карточек → 559: объединены шесть пар повторных записей проекта. Старые ссылки сохранены.
В галереях убраны 349 повторных вхождений идентичных файлов.
Исходные объединённые записи сохранены в mergedRecords. Подробности в DEDUP_REPORT.txt.
Карточки с одинаковым названием, но разными площадками, не объединены. Две пары с совпадающими фотографиями и разными адресами требуют проверки подписей.

ПРОВЕРКА
Проверены синтаксис JS, ссылки на изображения и декодирование изображений, целостность ZIP.
В DOM-среде проверены каталог, мобильные фильтры, старые ссылки, свайп, оригиналы в просмотре, перестановка фото, восстановление IndexedDB, даты, предпросмотр и экспорт.
Для проверки загрузки новых фото обработка canvas имитировалась; сохранение исходных байтов проверено в экспортированном ZIP.
Настоящий браузер в среде проверки был недоступен. Визуальное поведение на iPhone/Android и FPS не измерены.
Внешняя публикация не выполнялась. Доступность без VPN зависит от хостинга и провайдера; внешних библиотек для новых функций нет.
