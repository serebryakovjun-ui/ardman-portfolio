Как опубликовать изменения

  1. Добавьте или отредактируйте объекты.
  2. Нажмите «Скачать обновление ZIP».
  3. Распакуйте архив прямо в папку Документы\GitHub\ardman-portfolio с заменой файлов.
  4. Откройте GitHub Desktop.
  5. В поле Summary напишите Обновление портфолио, нажмите Commit to main, затем Push origin.
  6. Через несколько минут публичный сайт обновится.
